# 噪音取证助手 v0.1.0

首个正式版本发布！基于 Rust + Tauri 重构，性能全面提升。

## ✨ 主要特性

### 🎯 核心功能
- ✅ **智能检测** - 自动识别录音中的噪音事件（撞击、拖拽、摩擦等）
- ✅ **降噪处理** - 基于 RNN 深度学习的底噪抑制
- ✅ **可视化分析** - 实时波形预览、事件标记、音频播放
- ✅ **人工复核** - 支持手动框选添加/删除事件
- ✅ **批量导出** - 生成 WAV 音频 + CSV 事件清单

### 📦 三种处理模式
- **整段降噪** - 保留完整录音 + 底噪抑制
- **整段放大** - 保留完整录音 + 归一化增益
- **智能切片** - 提取噪音片段 + 合成导出

### 🚀 性能优势
- **10x+ 处理速度** - 相比 Python 版本
- **更小的安装包** - 仅 2.4 MB（NSIS 安装程序）
- **原生性能** - Rust 编写，无运行时依赖
- **低资源占用** - 内存友好，适合长时间录音

## 📦 下载

### Windows 安装包（推荐）

**文件名**: `噪音取证助手_0.1.0_x64-setup.exe`  
**大小**: 2.4 MB

**安装步骤：**
1. 下载安装包
2. 双击运行安装向导
3. 按提示完成安装

**文件名**: `噪音取证助手_0.1.0_portable.exe`  
**大小**: ~11 MB  
**说明**: 直接运行，无需安装

## 📖 快速开始

1. **导入录音** - 点击"导入录音"按钮
2. **查看检测结果** - 系统自动分析并标记噪音事件
3. **调整参数**（可选） - 灵敏度、响度门限、降噪开关等
4. **人工复核** - 在波形上框选新增事件或删除误检
5. **导出证据** - 生成 WAV 音频和 CSV 清单

详细使用指南请参考 [README.md](https://github.com/Zenfish-zy/Noise-Extraction/blob/main/README.md)

## ⚖️ 取证边界

本工具用于辅助定位和整理录音中的可疑噪音事件。事件分类和"疑似录制混入"只提供声学线索，不能单独证明声音来源；最终证据判断仍应结合原始录音、录制时间、环境记录和人工复核。
